
Part two of my cauldron to block projects, the first being https://modrinth.com/plugin/cauldron-concrete. Inspired by Vanilla Tweaks' Cauldron Mud datapack, this is a more lag efficient plugin based version! Toss in your concrete powder, and watch the magic happen! 

_This was created for use on my forever world, called "derex smp". Check it out in action, server ip: `mc.longhorns.dev`_

### Features:
- Supports multiple types of dirt being dropped into a cauldron, such as dirt, coarse dirt, rooted dirt, and more!
- It remains vanilla friendly by lowering the water level of the cauldron, meaning players will have to find a clever way to replenish the cauldron, leading to more automation options in vanilla Minecraft while saving so much time.
- Optimized for servers! Datapacks do checks way too often, and using unoptimized Minecraft functions. This plugin will only listen for dirt types itself in the cauldron block, leading to much less performance impacts.
